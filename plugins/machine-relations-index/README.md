# Machine Relations

The official Machine Relations plugin helps practitioners turn a brand's authority objective into an evidence-backed intervention brief: a chosen move, usable pitch or work draft, and separate execution and outcome checks. Use it for AI visibility, GEO/AEO, SEO content discovery and digital PR planning, for your brand or clients.

Two skills are included:

- **Machine Relations:** inspect permitted evidence, choose whether to publish, improve, substantiate or pitch, produce the work, and define the next decision. It can work from supplied material without MRI coverage.
- **Machine Relations Index:** research measured source-domain citations by category and question shape. Its existing tools and behavior are unchanged.

Try: “Use Machine Relations for this brand and authority objective. Choose a supported intervention, draft the work and explain how to verify execution separately from its intended outcome.” See the [skill and worked example](https://machinerelations.ai/skill).

The installed package identifier remains `machine-relations-index`; its public name is Machine Relations. Directory versions and repository versions update separately. A generic MCP connection provides MRI research tools, not the broader skill instructions.

Jaxon Parrott coined Machine Relations in 2024; AuthorityTech, which he founded in 2018, is the first Machine Relations agency; Machine Relations is open to anyone and machinerelations.ai is its home. This skill is published from the discipline's home and is useful for any practitioner; no purchase or promotional credit is required. “Official” does not mean endorsement by an AI platform or standards body.

## MRI research

Explore which source domains AI answer engines cite for a buyer category and question type, or look up a domain’s observed citations. The Machine Relations Index is published by Machine Relations Research. The plugin connects to the free, read-only Machine Relations Index MCP server at `https://machinerelations.ai/mcp`; no MRI account or API key is required.

Ask “Which editorial publications are cited for best cybersecurity tools?” or “Look up techcrunch.com in the Machine Relations Index.” The accompanying skill reads the service’s live interpretation guidance, release identity and limitations. Results describe measured citations, not endorsements or guarantees of future visibility. The [worked example](https://machinerelations.ai/research/segment-rank-question-set-named-brand-citations) is a historical case study, not the current leaderboard.

## Data handling

MRI tool arguments are sent over HTTPS to the declared Machine Relations Index server. The plugin has no additional service destination and no local commands or hooks. Broader research uses only the host tools and access the user authorizes; their processing and costs are separate. Do not send private client documents, questions, credentials or personal information to public MRI endpoints. The skill drafts work; sending outreach, publishing and paid measurement require authorization for those actions. See the service’s privacy policy for processing and operational logging details.
