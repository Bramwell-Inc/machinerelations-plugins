# MRI review walkthrough

The video walks through actual live MCP responses captured on October 2, 2026. It is an evidence presentation, not a recording of an assistant conversation. The JSON files preserve the requests, responses and capture timestamps for the five positive review scenarios. `tools.json` preserves discovery and annotations. Negative cases are scope expectations, not claimed model-level test results.

Endpoint: https://machinerelations.ai/mcp (stateless Streamable HTTP, no authentication).

The video and evidence demonstrate category discovery, category detail, editorial filtering, domain lookup, absence handling, citations and the four-tool read-only scope. Reviewers can reproduce the requests with any MCP client. No test credentials are required.
